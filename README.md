# SKILLER Landing Page

A simple landing page for SKILLER - an app to learn football from home.

## About
SKILLER is a subscription-based digital football coaching application with video-based lessons, progress tracking, and community features.

## Features
- Video coaching lessons
- Progress tracking by position (striker, midfielder, defender, goalkeeper)
- Community leaderboard
- Social sharing
